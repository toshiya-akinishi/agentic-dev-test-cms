# agentic-dev-test-cms

**J-Tour Fan App** のバックエンド（CMS / API / テストデータ）。

## 技術スタック

- Payload CMS v3（Next.js App Router 同梱）
- SQLite（`@payloadcms/db-sqlite`）
- TypeScript
